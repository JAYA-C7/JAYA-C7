## 🚀 Featured Project

### 🍽️ Smart Canteen Ordering Application

A full-stack web application designed to simplify food ordering and canteen management.

**Tech Stack:** React.js · JavaScript · Node.js · Express.js · MySQL · JWT · bcrypt

#### Key Features

* 👤 Student registration, login, and role-based access.
* 🍔 Food menu browsing, search, and category filtering.
* 🛒 Shopping cart and order placement.
* 📦 Order history, order tracking, and status updates.
* 🛡️ Admin dashboard for food and order management.
* 📊 Inventory monitoring and sales reports.
* 🔔 Notifications and food nutrition information.
* 💬 Rule-based chatbot for canteen-related questions.
* 🔗 REST APIs connected to a MySQL relational database.
